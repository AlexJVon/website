Portfolio Quest

Explore · Interactive Portfolio Navigator

Open in New Tab ↗

How to play:

Use W A S D or ↑ ↓ ← → to walk around, and E to interact with a terminal.

This isn't just a maze to wander — it's a working way to browse the site. Each terminal takes you to a different page: About, Projects, and Home will navigate you straight there, and Connect opens my social links.

Cipher Terminal

Typing Speed · Hacker Terminal

Open in New Tab ↗

How to play:

Type each terminal line exactly as shown before the 60-second clock runs out. Speed (WPM) and accuracy both feed your final score.

Built with vanilla JavaScript — no canvas, just DOM and a lot of keystroke tracking.

Wordle Labyrinth

Puzzle · Word Game · Maze

Open in New Tab ↗

How to play:

Use W A S D or ↑ ↓ ← → to navigate the maze. Find the exit hidden in the fog of war. Toggle "Reveal Exit" to show the goal location.

Built with vanilla JavaScript and HTML5 Canvas. View source on GitHub ↗

Neon Flap

Arcade · Flappy Bird Style

Open in New Tab ↗

How to play:

Press Space, ↑, or tap the canvas to flap. Thread the neon pipes without hitting the ground or a pipe. Speed and pipe gap ramp up as your score climbs.

Built with vanilla JavaScript and HTML5 Canvas. View source on GitHub ↗
